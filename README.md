# Denko

メニューバーが、小さな駅の電光掲示板になる Mac アプリです。

- **掲示板**：天気、ニュース速報、電車の遅延、地震・津波、コーディングエージェントのお知らせが、ドットの文字で流れます。大事なお知らせは、駅の緊急案内のようにメニューバー全体に流れます。
- **Mac の使用状況**：お知らせがないあいだは、CPU・メモリ・通信の使用量（とカエル）を掲示板に映します。クリックすると、どのアプリが使っているかを円グラフで確認できます。
- **AI の使用量**（任意）：Claude・Codex の利用枠（5時間・1週間）を二重のリングで表示します。
- **コーディングエージェント連携**：Claude Code・Codex の許可待ちや作業完了を流します。Gemini CLI・Antigravity・Cursor などもつなげられます → [連携ガイド](INTEGRATIONS.md)

## 動作環境

macOS 14 以降。Apple シリコン・Intel のどちらでも動きます。

## インストール

[Releases](https://github.com/oriharu-heaven/Denko/releases/latest) から DMG をダウンロードし、Denko を「アプリケーション」へドラッグしてください。
Homebrew でも入れられます。

```bash
brew install --cask oriharu-heaven/tap/denko
```

新しい版が出ると、アプリが自動でお知らせします。

## プライバシー

- 使用量やお知らせは、すべてこの Mac の中で処理します。Denko が外部に送るデータはありません（分析・トラッキングもありません）。
- AI の使用量は、ログイン情報を使わずに受け取ります。Claude は Claude Code がステータスラインに知らせる値を、Codex はこの Mac にある Codex CLI の記録を読みます。
- ストレージ分析の「かんたん」は、macOS がアクセスの確認を出す場所（書類・デスクトップ・他のアプリのデータ）を読みません。

## 情報の取得元

| 情報 | 取得元 |
|---|---|
| 天気 | [Open-Meteo](https://open-meteo.com)（CC BY 4.0） |
| 地震・津波・気象警報 | 気象庁 防災情報XML |
| ニュース | Yahoo!ニュース トピックス（RSS） |
| トレンド | Google トレンド（急上昇ワード RSS） |
| 運行情報 | 公共交通オープンデータセンター（都営。東京メトロなどは自分で登録したトークンで） |
| 為替 | Frankfurter（欧州中央銀行の参考レート） |

緊急地震速報（揺れる前の警報）には対応していません。防災情報は参考として使い、公的な情報も確認してください。

Denko は非公式アプリで、Anthropic・OpenAI・Google・鉄道各社・気象庁とは関係ありません。
